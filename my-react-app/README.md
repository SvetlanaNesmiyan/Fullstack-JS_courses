# User Profile React App

Простий React-додаток для відображення профілю користувача з використанням Vite.

## Опис

Цей проект демонструє:
- Створення React-компонентів за допомогою Vite
- Виконання асинхронних GET-запитів до API
- Обробку станів завантаження, успіху та помилки
- Написання тестів з використанням Vitest та @testing-library/react

## Функціональність

Компонент `UserProfile` виконує асинхронний GET-запит до API [JSONPlaceholder](https://jsonplaceholder.typicode.com/users/1) та відображає:
- Індикатор завантаження під час виконання запиту
- Дані користувача (ім'я, email, телефон, місто, компанія) після успішного запиту
- Повідомлення про помилку у разі невдалого запиту

## Тести

Проект включає тести, які перевіряють:
1. Відображення індикатора завантаження під час виконання запиту
2. Коректне відображення даних користувача після успішного запиту
3. Відображення повідомлення про помилку у разі невдалого запиту (HTTP-помилка)
4. Відображення повідомлення про помилку при виключенні (network error)

## Встановлення

```bash
# Клонування репозиторію
git clone <URL_REPOSITORY>
cd my-react-app

# Встановлення залежностей
npm install
```

## Запуск

### Режим розробки
```bash
npm run dev
```

### Запуск тестів
```bash
npm test
```

### Збірка для продакшену
```bash
npm run build
```
