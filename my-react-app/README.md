# React Components Demo

Демонстраційний React додаток, створений за допомогою Vite. Проект демонструє різні типи компонентів: **Stateful**, **Stateless** та **Class-based**.

## Опис проекту

Цей проект створено для навчання та демонстрації різних підходів до створення React компонентів:

- **Stateful компоненти** - компоненти зі власним станом, використовують хук `useState`
- **Stateless компоненти** - компоненти без стану, які отримують дані через пропси
- **Class компоненти** - класичний підхід до створення компонентів з використанням класів ES6

## Встановлення та запуск

## Компоненти

### StatefulComponent

Компонент зі станом, який використовує хук `useState` для управління:
- Лічильником (кнопки "+" та "-")
- Текстовим полем вводу

**Особливості:**
- Використовує `useState` для управління станом
- Демонструє оновлення стану через `setState` функцію
- Показує принцип роботи з формами

```jsx
import StatefulComponent from './components/StatefulComponent';

<StatefulComponent />
```

### StatelessComponent

Компонент без власного стану, який отримує всі дані через пропси та відображає їх.

**Props:**
- `title` (обов'язковий) - заголовок секції
- `description` - опис (за замовчуванням: порожній рядок)
- `items` - масив елементів для відображення (за замовчуванням: порожній масив)
- `onItemClick` - функція обробник кліку по елементу

```jsx
import StatelessComponent from './components/StatelessComponent';

<StatelessComponent
  title="Інформація"
  description="Опис компонента"
  items={['Елемент 1', 'Елемент 2']}
  onItemClick={(item) => console.log(item)}
/>
```

### ClassComponent

Класовий компонент, який відтворює функціональність StatefulComponent з використанням класів ES6.

**Особливості:**
- Використовує `constructor` для ініціалізації стану
- Демонструє методи життєвого циклу: `componentDidMount`, `componentDidUpdate`, `componentWillUnmount`
- Показує прив'язку контексту (`bind`) для методів

```jsx
import ClassComponent from './components/ClassComponent';

<ClassComponent title="Лічильник" />
```

## Порівняння підходів

### Функціональні компоненти vs Класові компоненти

| Аспект | Функціональні | Класові |
|--------|---------------|---------|
| **Синтаксис** | Прості функції | Класи ES6 |
| **Стан** | useState хук | this.state |constructor` для ініціалізації |
| **Життєвий цикл** | useEffect хук | Методи життєвого циклу |
| **this** | Не потрібен | Потрібна прив'язка |
| **Розмір коду** | Компактніший | Більш багатослівний |
| **Читабельність** | Вища | Нижча |
| **Сумісність** | Сучасний підхід | Легасі підхід |

### Рекомендації

1. **Використовуйте функціональні компоненти** для нових проектів
2. **Хуки (useState, useEffect)** роблять код простішим і зрозумілішим
3. **Розділяйте компоненти** на stateful (логіка) та stateless (відображення)
4. **Використовуйте деструктуризацію** для роботи з пропсами
