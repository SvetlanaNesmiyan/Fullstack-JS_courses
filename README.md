# React Context Demo

Демонстраційний проект, що ілюструє використання React Context API для управління глобальним станом додатку.

## 📖 Опис проекту

Цей проект демонструє:
- Створення контексту за допомогою `createContext`
- Реалізацію провайдера контексту з глобальними даними
- Використання хука `useContext` у вкладених компонентах
- Передачу даних без пропсів (prop drilling)
- Перемикання теми (світла/темна)
- Управління списком користувачів

## 🏗️ Структура проекту

```
my-context-app/
├── src/
│   ├── context/
│   │   └── AppContext.jsx      # Контекст та провайдер
│   ├── components/
│   │   ├── UserList.jsx        # Список користувачів
│   │   ├── UserProfile.jsx     # Профіль користувача
│   │   └── ThemeToggle.jsx     # Перемикач теми
│   ├── hooks/
│   │   └── useAppContext.js    # Кастомний хук для контексту
│   ├── App.jsx                 # Головний компонент
│   ├── App.css                 # Стилі додатку
│   ├── main.jsx                # Точка входу
│   └── index.css               # Глобальні стилі
├── package.json
└── README.md
```

## 🚀 Встановлення та запуск

### Передумови
- Node.js (версія 16 або вище)
- npm або yarn

### Кроки встановлення

1. Клонуйте репозиторій:
```bash
git clone <посилання-на-репозиторій>
cd my-context-app
```

2. Встановіть залежності:
```bash
npm install
```

3. Запустіть проект у режимі розробки:
```bash
npm run dev
```

4. Відкрийте браузер за адресою `http://localhost:5173`

## 🔧 Функціональність

### Управління користувачами
- Перегляд списку користувачів
- Додавання нових користувачів
- Видалення користувачів
- Перегляд профілю користувача

### Перемикання теми
- Світла тема (за замовчуванням)
- Темна тема
- Плавний перехід між темами

## 📚 Використані технології

- **React 18** - бібліотека для створення UI
- **Vite** - інструмент для збірки проекту
- **Context API** - управління глобальним станом
- **React.memo** - оптимізація компонентів
- **useCallback & useMemo** - оптимізація продуктивності

## 🎯 Ключові особливості

1. **Контекст з осмисленими значеннями за замовчуванням** - запобігає помилкам через `undefined`

2. **Кастомний хук useAppContext** - забезпечує перевірку наявності провайдера

3. **Оптимізація з React.memo** - компоненти мемоізовані для уникнення зайвих ре-рендерів

4. **Мемоізація значень контексту** - використання `useMemo` та `useCallback` для оптимізації
