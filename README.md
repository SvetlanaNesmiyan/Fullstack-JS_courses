# 🚀 React Router App

Цей проект демонструє використання React Router для клієнтської маршрутизації в React-додатку, створеному за допомогою Vite.

## 📋 Опис проекту

Додаток демонструє:
- Налаштування маршрутизації за допомогою `createBrowserRouter` та `RouterProvider`
- Використання `NavLink` для навігації з активними стилями
- Динамічне створення маршрутів з масиву об'єктів
- Використання `Outlet` для вкладених маршрутів
- Перехід між сторінками без перезавантаження браузера (SPA)

## 🛠️ Технології

- **React 19** - бібліотека для створення користувацьких інтерфейсів
- **Vite** - інструмент для швидкої розробки та збірки
- **React Router 7** - бібліотека для маршрутизації

## 🚀 Встановлення та запуск

### Передумови

- Node.js (версія 18 або вище)
- npm або yarn

### Кроки встановлення

1. **Клонування репозиторію:**
   ```bash
   git clone <посилання-на-репозиторій>
   cd my-react-router-app
   ```

2. **Встановлення залежностей:**
   ```bash
   npm install
   ```

3. **Запуск в режимі розробки:**

## ✨ Особливості реалізації

### Динамічне створення маршрутів

Маршрути створюються динамічно з масиву об'єктів, що дозволяє легко додавати нові сторінки:

```jsx
export const routes = [
  { path: '/', element: <Home />, name: 'Домашня' },
  { path: '/about', element: <About />, name: 'Про нас' },
  { path: '/contact', element: <Contact />, name: 'Контакти' },
];
```

### Layout з Outlet

Використовується компонент Layout з Outlet для вкладених маршрутів:

```jsx
function Layout() {
  return (
    <div className="app">
      <nav className="navbar">
        {/* Навігація */}
      </nav>
      <main className="main-content">
        <Outlet />
      </main>
    </div>
  );
}
```

### Активні посилання з NavLink

Використовується `NavLink` з функцією `isActive` для стилізації активного посилання:

```jsx
<NavLink
  to={route.path}
  className={({ isActive }) =>
    isActive ? 'nav-link active' : 'nav-link'
  }
>
  {route.name}
</NavLink>
```
