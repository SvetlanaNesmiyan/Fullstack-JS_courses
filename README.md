# React Memoization Demo

Демонстраційний React-додаток, який ілюструє використання мемоізації для оптимізації продуктивності.

## 📋 Опис проекту

Цей проект демонструє три основні техніки мемоізації в React:

1. **useMemo** - мемоізація обчислень
2. **useCallback** - мемоізація колбек-функцій
3. **React.memo** - мемоізація компонентів

## 🚀 Функціональність

### Демонстрація useMemo

Компонент [`FibonacciCalculator.jsx`](src/components/FibonacciCalculator.jsx) показує:
- Обчислення чисел Фібоначчі з мемоізацією та без неї
- Лічильник кількості обчислень для порівняння
- Як useMemo допомагає уникнути непотрібних перерахунків

### Демонстрація useCallback

Компонент [`CallbackDemo.jsx`](src/components/CallbackDemo.jsx) демонструє:
- Передачу функцій дочірнім компонентам
- Різницю між мемоізованими та немемоізованими колбеками
- Як useCallback запобігає непотрібним ререндерам

### Демонстрація React.memo

Компонент [`ReactMemoDemo.jsx`](src/components/ReactMemoDemo.jsx) показує:
- Порівняння звичайних та мемоізованих компонентів
- Як React.memo оптимізує рендеринг списків
- Важливість використання useCallback разом з React.memo

### API Демонстрація

Компонент [`UserProfile.jsx`](src/components/UserProfile.jsx) - приклад реального використання:
- Асинхронний запит до API
- Обробка станів завантаження та помилок

## 💡 Як використовувати демо

1. **Відкрийте додаток** в браузері
2. **Відкрийте консоль** (F12 -> Console) для перегляду логів
3. **Натискайте на кнопки** в навігації для перемикання демонстрацій
4. **Спостерігайте за логами** - там видно скільки разів відбувається рендеринг

### useMemo демо
- Змінюйте число і спостерігайте за лічильниками обчислень
- Версія з useMemo показує значно менше обчислень

### useCallback демо
- Натискайте "Збільшити лічильник" 
- Кнопка з useCallback не ререндериться

### React.memo демо
- Натискайте "Оновити батька"
- Список з React.memo не перерендериється

## 🔍 Коли використовувати мемоізацію

### useMemo
- Важкі обчислення (фільтрація, сортування, агрегація)
- Дані, які рідко змінюються
- Уникнення зайвих обчислень при ререндері

### useCallback
- Передача функцій до memo-зованих компонентів
- Функції в залежностях useEffect
- Функції, що використовуються в дочірніх компонентах

### React.memo
- Компоненти, які ререндеряться часто
- "Дорогі" компоненти (списки, великі таблиці)
- UI компоненти, які не залежать від часто змінюваних даних

## ⚠️ Важливо пам'ятати

1. **Не зловживайте мемоізацією** - вона має свою ціну (пам'ять, процесор)
2. **Спочатку оптимізуйте алгоритми** - хороший алгоритм важливіший за мемоізацію
3. **Використовуйте React DevTools Profiler** для пошуку проблем з продуктивністю
4. **Мемоізація не бесплатна** - створює залежності, які потрібно контролювати
