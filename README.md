# HTTP Server

Простий HTTP сервер з HTML сторінками та обробкою форм.

## Опис

Цей проект реалізує HTTP сервер на Node.js з використанням нативного модуля `http`. Сервер підтримує HTML сторінки, обробку форм та базову валідацію даних.

## Технології

- Node.js (native http module)
- ES Modules (.mjs)

## Встановлення

1. Клонуйте репозиторій
2. Встановіть залежності (якщо є):
   ```bash
   npm install
   ```

## Запуск

Запустіть сервер:
```bash
npm start
```

Сервер буде доступний за адресою: http://localhost:3000

## Доступні маршрути

### GET запити
- **GET /** - повертає Home сторінку з заголовком "Home" та текстом "Welcome to the Home Page"
- **GET /about** - повертає About сторінку з заголовком "About" та текстом "Learn more about us"
- **GET /contact** - повертає Contact сторінку з заголовком "Contact" та текстом "Get in touch"
- **GET /{інший шлях}** - повертає 404 сторінку "Page Not Found"

### POST запити
- **POST /submit** - обробляє форму з полями name та email
  - При успішній валідації повертає сторінку "Form Submitted" з введеними даними
  - При невалідних даних (порожні поля) повертає 400 з повідомленням "Invalid form data"
  - При помилці сервера повертає 500 з повідомленням "Error 500"

### PUT запити
- **PUT /** - повертає 405 "Method Not Allowed"

## Безпечні заголовки

Сервер додає наступні заголовки до відповідей:
- `Content-Type: text/html; charset=utf-8`
- `X-Content-Type-Options: nosniff`

## Тестування

Проект включає тести Vitest у файлі `server.test.mjs`. Для запуску тестів:
```bash
npm test
```

## Архітектура

Сервер використовує нативний Node.js модуль `http` без зовнішніх залежностей. Основний файл [`src/server.mjs`](src/server.mjs) експортує об'єкт сервера для можливості тестування.

Сервер запускається на порту 3000 за замовчуванням. Змінити порт можна у файлі [`src/server.mjs`](src/server.mjs:78).
