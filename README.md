# Книга Фанфиков

React-приложение с pixel-perfect реализацией header-компонента для сайта фанфиков.

## 🛠 Технический стек

- **Vite** — сборщик и инструмент разработки
- **React 18** — библиотека для создания пользовательских интерфейсов
- **TypeScript** — типизированный JavaScript
- **Redux Toolkit** — управление состоянием приложения
- **CSS Modules / CSS** — стилизация компонентов

## 📁 Структура проекта

```
fanfic-book/
├── src/
│   ├── assets/           # Статические ресурсы (изображения, шрифты)
│   ├── components/       # React-компоненты
│   │   ├── Header/      # Header компонент
│   │   ├── ErrorBoundary/  # Обработка ошибок
│   │   └── Loading/     # Компонент загрузки
│   ├── redux/           # Redux хранилище и срезы
│   │   ├── store.ts     # Конфигурация хранилища
│   │   ├── hooks.ts     # Типизированные хуки
│   │   ├── selectors.ts # Memoized селекторы
│   │   ├── uiSlice.ts  # Срез UI-состояния
│   │   └── navigationSlice.ts  # Срез навигации
│   ├── App.tsx          # Главный компонент приложения
│   ├── main.tsx         # Точка входа
│   └── index.css        # Глобальные стили
├── index.html           # HTML-шаблон
├── package.json         # Зависимости проекта
├── tsconfig.json       # Конфигурация TypeScript
└── vite.config.ts      # Конфигурация Vite
```

## 🚀 Установка и запуск

### Установка зависимостей

```bash
npm install
```

### Запуск dev-сервера

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173/`

### Сборка для продакшена

```bash
npm run build
```

### Предварительный просмотр продакшен-сборки

```bash
npm run preview
```

Компонент `Header` реализует точную копию макета и включает:

- **Логотип и название сайта**: "Книга Фанфиков"

- **Дополнительная панель ссылок**: FAQ, Правила

### Функциональность

- Фиксированное позиционирование (sticky header)
- Полная адаптивность (desktop, tablet, mobile)
- Подключение к Redux-состоянию для управления активным пунктом меню
- Обработчики событий для кнопок (поиск, случайная работа, добавление фанфика)
- Семантическая HTML5-разметка
- Доступность (ARIA-атрибуты, клавиатурная навигация)

## 🔧 Redux Store

### UI Slice

Управляет глобальным UI-состоянием:
- `isLoading` — состояние загрузки
- `error` — сообщение об ошибке
- `searchQuery` — поисковый запрос
- `isSearchOpen` — видимость модального окна поиска
- `isMobileMenuOpen` — видимость мобильного меню

### Navigation Slice

Управляет состоянием навигации:
- `primaryNavItems` — основные пункты меню
- `secondaryNavItems` — дополнительные ссылки
- `activeNavItem` — активный пункт меню
- `hoveredNavItem` — пункт меню при наведении

## ♿ Доступность

- ARIA-атрибуты для компонентов
- Семантическая HTML-разметка
- Поддержка клавиатурной навигации
- Контрастный цветовой дизайн
- Адаптивная верстка для всех устройств
